## 设计说明

- 三个模块在底部同一个悬浮气泡里切换：**天气 / 路况 / 雪道**。
- 右侧圆形三条横线是“上下文切换”：
  - 天气、雪道：切换雪场
  - 路况：切换路线
- 天气页内容零改动，只新增底部导航、内容底部留白和安全区。
- 路况页突出三件事：
  - 三条主要路线（京礼、京藏+张承、京新+张承）的通行状态
  - 封路的具体路段、方向、原因、预计恢复、绕行
  - 沿线能见度/天气，以及出发建议
- 雪道页突出：
  - 开放数量、缆车数量、各难度数量
  - 雪道开放示意图（原创示意，非官方雪道图）
  - 开放时间轴（过去事件 + 官方预计）
  - 单条雪道的状态、预计开放、来源、更新时间

## 数据说明（重要）

效果图里的路况和雪道状态是演示数据，标注了“示意”或“官方来源”。正式上线不能假装实时：

- **路况**：免费公开 API 无法稳定拿到跨省高速的官方封路明细。需要组合：
  - 有授权的地图交通态势 API（拥堵/速度）
  - 北京交通委开放数据（公路事件，需申请）
  - 河北高速交警 / 12122 / 中国路网等官方发布（人工核验或合作接口）
  - 自己的“路况登记表”兜底，并显示来源和时间
- **雪道**：微信公众号没有公开 API，不能稳定自动抓取。建议：
  - 以雪场官方公众号/公告为准，人工或半自动录入
  - 每条状态保留“来源 + 更新时间”
  - 预计开放只展示官方明确说过的；没有就写“待官方公布”
- **雪道图**：正式版不要直接使用官方雪道图，除非拿到授权。效果图里的示意图是原创抽象图，不代表真实比例。
- 所有“封路/开放”信息都要有“以官方为准”的免责声明，不能把估算当官方状态。
