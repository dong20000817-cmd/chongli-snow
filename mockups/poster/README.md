## 能微调什么

- **日期**：今天 / 明天
- **雪场范围**：全部 8 家 / 崇礼 7 家 / 自选
- **显示指标**：山顶温度、风级、能见度、体感（可开关）
- **版式**：榜单（默认）/ 双列 / 单雪场
- **主题**：雪夜 / 晨光 / 雾雪
- **尺寸**：3:4 小红书 1080×1440 / 9:16 故事 / 1:1 方图
- **文字**：主标题、副标题、署名（小红书号）、数据脚注开关

微调结果存 `localStorage`，下次打开保持上次设置。

## 保存到手机相册：必须先说清楚

**iOS Safari 不允许网页静默写入「照片」。** 任何声称“点一下直接进相册”的网页方案都不稳定。  
可靠路径只有一条：

```text
保存到相册
  → 生成 1080×1440 PNG
  → 调起 iOS 系统分享面板
  → 点「存储图像」
  → 图片进入「照片」App
```

也就是 **2 步确认**，不是 0 步。设计稿里的分享面板就是这个流程。

兜底：

- 如果系统分享没弹出来：长按预览图 → `存储到照片`
- 桌面浏览器：直接下载 PNG
- 旧版浏览器不支持文件分享：下载到「文件」App，再手动存相册

正式版不会做“假装已经保存”的提示。
