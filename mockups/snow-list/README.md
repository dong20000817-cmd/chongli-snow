# 雪道开放 · 分类列表效果图

这是“不做矢量雪道图，改为按绿道/蓝道/黑道/双黑分类列表”的设计稿。  
天气、路况模块不变；只改雪道开放页。

1. 首屏：`screens/01-list-top.png`
2. 完整长图：`screens/02-list-full.png`
3. 筛选“黑道”：`screens/03-list-black.png`

## 设计说明

- 顶部先给总量：今日开放 13/32、缆车 4/7、今日新增、预计明天。
- 一行“全部 / 绿道 / 蓝道 / 黑道 / 双黑”筛选，每个分类带开放数。
- 每个分类一块：
  - 分类名、难度、开放数
  - 一句文字描述：哪些雪道开放、雪质/风况/适合人群
  - 开放雪道列表：名称、长度、备注、开放状态
  - 底部：还有多少条关闭，可查看全部
- 双黑没有开放时，用空状态展示“当前无开放雪道”，列出预计开放的大奔头等。
- 底部“未来 3 天预计”，只展示官方明确说过的开放计划。
- 数据来源、更新时间、免责声明固定展示。

## 为什么这个方向更稳

- 不需要画 8 家雪场的矢量图，开发量小很多。
- 不涉及官方雪道图版权。
- 雪道名称、数量、开放状态用文字列表表达，信息更准确，也不容易因为示意图比例误导。
- 以后加雪场、加雪道只需要加数据。
- 适合先快速上线，再决定是否做图。

## 数据说明

- 雪道状态仍来自雪场官方公众号/公告，人工或半自动整理。
- 微信公众号没有公开 API，不能承诺“官方实时”。
- 每条数据保留来源和更新时间；预计开放只展示官方明确说过的。
- 效果图中的 13/32、各分类数量、雪道名称为演示数据，不是万龙真实开放情况。
